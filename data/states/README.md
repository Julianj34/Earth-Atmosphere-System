# Layer States

This folder contains the latest generated JSON state files for each system layer.

Each file represents the current state of one layer:

- `layer0_test_state.json` – External Drivers
- `layer1_test_state.json` – Planetary Body / Ground State
- `layer2_test_state.json` – Surface & Near-Biosphere Contact Zone
- `layer3_test_state.json` – Atmosphere / Weather / Convection
- `layer4_test_state.json` – Ionosphere
- `layer5_test_state.json` – Global Electric Circuit
- `layer6_test_state.json` – Resonance Field / Schumann Layer
- `layer7_test_state.json` – Integrated Earth Field Snapshot
- `layer8_test_state.json` – Research & Hypothesis Engine State

These state files allow information to move from lower layers into higher layers.

Layer 8 uses the long-term Layer 7 history to create a research state based on patterns, transitions and hypotheses.
