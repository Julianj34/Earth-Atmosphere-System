# Layer 7 History

This folder contains the long-term Layer 7 snapshot history.

The main file is:

- `layer7_test_history.jsonl`

Each line represents one full Earth Field snapshot.

This history is important for later Layer 8 analysis, because repeated snapshots allow the system to detect:

- recurring system states
- morning vs. evening differences
- slow cross-layer couplings
- state transitions
- potential hypotheses
